# Retired legacy path

The tracked `RC522_Basic` ESP8266/Wemos D1 Mini sketch and its board
configuration were removed. Historical source remains available in Git
history only; this path is not a supported spot-writer build.

Use [`../esp32/`](../esp32/) for the only supported ESP32-C3 / LOLIN C3 Mini
spot writer, which implements the [current wand NFC contract](../../docs/reference/wand-nfc-data-contract.md)
and portable codec.
