# Current spot writer platform

The current deployment target is the ESP32-C3 on a LOLIN C3 Mini with a PN532 reader over I2C. Wemos D1 Mini / ESP8266 paths are historical only because the current management and field workflow depends on the C3 Mini's USB and Bluetooth configuration path. Their explicit retirement is recorded in [0006](0006-retire-legacy-esp8266-spot-writers.md).
