# Repository Audit Skill

This skill provides procedures for auditing the Tryllestavsprojekt repository to ensure all changes conform to guidelines.

## Procedures

1. **Verify Alignment**: Ensure any code changes are fully aligned with the design principles in `docs/02-VISION-AND-PURPOSE.md`.
2. **Review Instructions**: Check `.github/instructions/` to confirm that standard Vue component guidelines, debugging rules, and project-vision instructions are followed.
3. **Documentation Sync**: Check `docs/MAINTENANCE.md` to guarantee that all source-of-truth documentation files are kept in sync with the codebase.
